# Hynex | E-commerce Abbigliamento

Sito e-commerce di abbigliamento urban/streetwear realizzato come progetto universitario per il corso di Programmazione Web.

## Tecnologie
- HTML, CSS, JavaScript vanilla
- Node.js (modulo http nativo)
- MySQL (libreria mysql2)

## Struttura progetto
- `/frontend` — pagine HTML, CSS, JavaScript
- `/backend` — server Node.js e connessione DB
- `/database` — schema SQL con tabelle e dati di esempio

## Come avviare il progetto
1. Importa lo schema del database: `database/schema.sql`
2. Modifica la password in `backend/db.js`
3. Installa le dipendenze: `npm install`
4. Avvia il server: `node backend/server.js`
5. Apri il browser su `http://localhost:3000`
